## Что такое Pulse Mobile?

**Pulse Mobile Client** — Android-приложение из экосистемы **Pulse** от **KirDev Studio**. Оно подключается к программе [Pulse-PC](https://github.com/kirdev07/Pulse-PC) на Windows и позволяет управлять компьютером через домашний Wi-Fi: от запуска программ и передачи файлов до переключения музыки и просмотра экрана.

Это **отдельный клиент**, а не самостоятельный сервер: для работы на компьютере должна быть запущена совместимая версия Pulse-PC с включённым локальным API.

> **Поддерживаемые платформы:** Android **11 (API 30) и новее** для телефона; **Windows** для компьютера. Поддержка часов / Wear OS в текущий проект не входит.

### Музыка без открытого приложения

В проекте реализован **PulseService** — Android foreground service с **MediaSession**:

- показывает название трека, исполнителя и обложку, когда данные доступны от ПК;
- добавляет медиакнопки управления в системные уведомления и на экран блокировки;
- обрабатывает Play / Pause, Next / Previous и перемотку;
- синхронизирует управление громкостью;
- сообщает о потере или восстановлении соединения и получает события Pulse-PC.

Фактическая работа медиасессий зависит от приложения-источника звука на Windows и возможностей серверного API.

### Файлы между телефоном и компьютером

- Навигация по доступным дискам и папкам Windows.
- Скачивание файлов в **Загрузки/PulsePC** на Android.
- Отправка выбранных документов и других файлов с Android на компьютер.
- Просмотр истории передач.
- Уведомление после успешного скачивания файла.

Пределы размера файлов и доступ к каталогам определяются сервером Pulse-PC и ресурсами устройства.

## Подключение к Pulse-PC

1. Установите и запустите **[Pulse-PC для Windows](https://github.com/kirdev07/Pulse-PC)**.
2. Включите локальный сервер / подключение телефонов в настройках Pulse-PC.
3. Подключите Android-телефон и ПК к **одной доверенной сети Wi-Fi**.
4. Запустите Pulse Mobile и выполните поиск компьютера.
5. Выберите найденный ПК и **подтвердите запрос сопряжения на самом компьютере**.
6. После подтверждения приложение сохранит подключение и откроет панель управления.

Клиент использует **UDP-обнаружение** (порт **8766**) и локальный HTTP API (по умолчанию порт **8765**). Обнаружение зависит от настроек роутера, брандмауэра Windows и доступности ПК. При проблемах проверьте, что устройства находятся в одной подсети и сеть не блокирует локальный трафик.

**Несколько ПК:** приложение хранит список ранее подключённых компьютеров и позволяет выбирать сохранённые подключения или забывать их. Удаление записи на телефоне не заменяет отзыв доступа на ПК: при необходимости удалите устройство и в Pulse-PC.

## Скачать или собрать

### APK

Откройте [**GitHub Releases**](https://github.com/kirdev07/Pulse-Mobile-Client/releases). Установочный APK будет доступен **только если он отдельно опубликован в выпуске**. Наличие исходников в репозитории само по себе не означает наличие готового APK.

### Сборка из исходников

**Понадобятся:** Android Studio, Android SDK для конфигурации проекта, JDK, совместимый с используемой версией Android Gradle Plugin, и интернет для первого скачивания зависимостей.

```powershell
git clone https://github.com/kirdev07/Pulse-Mobile-Client.git
cd Pulse-Mobile-Client
.\gradlew.bat assembleDebug
```

После успешной сборки отладочный APK обычно находится в:

```text
app/build/outputs/apk/debug/app-debug.apk
```

Можно открыть проект в Android Studio, дождаться синхронизации Gradle и запустить конфигурацию **app** на телефоне с Android 11+.

**Параметры текущего проекта:** `applicationId: com.kirdev.pulsepc`, `minSdk: 30`, `versionName: 1.0`. Подписанный релизный APK требует отдельной настройки подписи; секреты и ключи подписи не должны попадать в Git.

## Безопасность: обязательно прочитайте

**Текущая версия передаёт данные по HTTP, без TLS/HTTPS.** При сопряжении и дальнейших запросах в локальной сети передаются данные, включая токен доступа. Это **не защищённый канал для использования в публичных или недоверенных сетях**.

- Используйте приложение только в **доверенной домашней/локальной сети**.
- **Не открывайте порты Pulse-PC в интернет** и не настраивайте прямой port forwarding.
- Подтверждайте сопряжение только собственных устройств.
- Отзывайте доступ потерянных или чужих телефонов через Pulse-PC.
- В текущей реализации данные сохранённых ПК, включая токены, записываются в **Android SharedPreferences без отдельного прикладного шифрования**. Защищайте доступ к устройству и не передавайте его разблокированным посторонним.
- В AndroidManifest отключено резервное копирование приложения (`allowBackup=false`).
- Разрешения приложения включают доступ к сети, состоянию Wi-Fi, уведомлениям и foreground service для воспроизведения.

Подробности: [SECURITY.md](SECURITY.md) и [PRIVACY_POLICY.md](PRIVACY_POLICY.md).

## Частые вопросы

**Работает без компьютера?** Нет, клиент управляет работающим Pulse-PC на Windows.

**Можно управлять ПК через мобильный интернет?** Текущая архитектура рассчитана на локальную сеть. Публиковать нешифрованный HTTP API в интернет небезопасно.

**Нужен Telegram на телефоне?** Для локального интерфейса Pulse Mobile — нет. Однако некоторые серверные компоненты Pulse-PC могут зависеть от запуска соответствующих служб.

**Почему ПК не находится?** Проверьте одну сеть Wi-Fi, разрешения брандмауэра, запущенный локальный API и отсутствие изоляции клиентов на роутере.

**Можно подключить несколько компьютеров?** Да, в клиенте предусмотрен список сохранённых ПК.

**Где взять Windows-версию?** [Pulse-PC](https://github.com/kirdev07/Pulse-PC).
