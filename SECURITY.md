# Безопасность Pulse Mobile Client

## Область применения

Pulse Mobile предназначен для управления **собственным Windows-компьютером** через **доверенную локальную сеть** и совместимый Pulse-PC.

## Важные ограничения текущей версии

1. **HTTP без TLS:** `PcApi.kt` использует `http://`; `AndroidManifest.xml` разрешает cleartext traffic. Токен доступа передаётся в заголовке `Authorization: Bearer` по незашифрованному соединению.
2. **Локальное хранение токенов:** `MainActivity.kt` сохраняет токены и сведения о ПК в обычных `SharedPreferences`, без отдельного шифрования на уровне приложения.
3. **Обнаружение по UDP:** запрос `PULSEPC?` рассылается в локальной сети на порт 8766; обнаружение само по себе не является аутентификацией.
4. **Зависимость от сервера:** подтверждение сопряжения, ограничения действий и отзыв устройств реализуются в Pulse-PC; клиент не заменяет эти проверки.
5. **Удаление ПК из списка клиента** не гарантирует отзыв серверного токена. Отзывайте устройство также в Pulse-PC.

## Рекомендации пользователям

- Подключайтесь только к домашнему или другому доверенному Wi-Fi.
- Не пробрасывайте HTTP-порт Pulse-PC в интернет.
- Подтверждайте только собственные устройства.
- Защищайте Android-устройство блокировкой экрана.
- При потере телефона немедленно отзывайте доступ в Pulse-PC.
- Не публикуйте токены, файлы подписи Android и конфигурации с секретами.

## Рекомендации для следующих версий

- Защитить транспорт с проверкой подлинности сервера (например, корректно настроенным TLS).
- Перенести токены в защищённое хранилище Android Keystore.
- Провести ручное тестирование сценариев сопряжения, отзыва, потери соединения и работы фонового сервиса.
