# Политика конфиденциальности Pulse Mobile Client

**Проект:** Pulse Mobile Client · **Автор:** KirDev Studio · **Редакция:** 22 октября 2026 года.

## Назначение

Pulse Mobile Client — Android-приложение для управления собственным Windows-компьютером с установленным Pulse-PC через локальную сеть. Этот документ описывает поведение, наблюдаемое в опубликованных исходниках текущей версии; он не является заявлением о независимом аудите всех сторонних компонентов.

## Какие данные обрабатываются

- **Сведения о ПК:** имя компьютера, IP-адрес, порт, состояние соединения и данные, предоставляемые локальным API.
- **Данные сопряжения:** название устройства, токен доступа, адрес и порт компьютера.
- **Системные действия:** команды управления программами, окнами, питанием, плеером и другими функциями Pulse-PC.
- **Файлы:** данные выбранных для отправки файлов и скачиваемые с ПК файлы; скачанные файлы сохраняются в папке загрузок Android.
- **Медиа и уведомления:** название трека, исполнитель, обложка, статус плеера и события, передаваемые компьютером.

## Где хранятся данные

Список сохранённых компьютеров и их токены доступа сохраняются **локально в Android SharedPreferences**. В текущем исходном коде не реализовано отдельное прикладное шифрование этих значений. Резервное копирование приложения средствами Android отключено (`allowBackup=false`).

## Куда передаются данные

Приложение отправляет запросы на IP-адрес компьютера с Pulse-PC в локальной сети. Для обнаружения используется UDP broadcast, для управления — HTTP. **HTTPS/TLS в текущем клиенте не используется**, поэтому данные и токены могут быть перехвачены участниками недоверенной сети.

В собственном коде приложения не обнаружена отдельная аналитическая или рекламная служба. Это не исключает сетевых взаимодействий Android и сторонних системных компонентов.

## Разрешения Android

Приложение запрашивает разрешения на сетевой доступ, получение информации о Wi-Fi/сети, показ уведомлений и использование foreground service для медиаплеера. Доступ к выбранным файлам предоставляется через системные механизмы Android.

## Управление данными

Пользователь может удалить сохранённое подключение в приложении. Для **отзыва ранее выданного токена** необходимо также удалить устройство в настройках Pulse-PC на компьютере. Удаление приложения удаляет его локальные данные в рамках обычных механизмов Android, но не удаляет файлы, уже скачанные в общую папку загрузок.

## Рекомендации по безопасности

Используйте Pulse Mobile только в доверенной локальной сети; не публикуйте HTTP API Pulse-PC в интернет. При потере телефона отзовите его доступ на компьютере.
